# weight-check UI

Vite + React 19 single-page app (TypeScript, TanStack Router, TanStack Query, Tailwind CSS v4) for the weight-check backend. You can use it to load and unload models, start benchmarks, and watch runs complete with their metrics. `pnpm build` emits a static bundle in `dist/`.

```sh
pnpm install
pnpm tauri dev               # desktop app; runs `pnpm dev` (http://localhost:5173) for the webview
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

The UI talks to the Rust core through Tauri commands (`invoke`), via `call()` in `src/lib/api/client.ts`. Opened in a plain browser tab (`pnpm dev` alone), every request fails with a hint to use the desktop app.

## Layout

```
src/routes/       file-based TanStack Router routes (/, /models, /benchmarks, /runs, /runs/$id)
src/routeTree.gen.ts  generated by the router plugin on dev/build; committed so typecheck works on a clean checkout
src/components/   ui/ primitives, plus layout/, system/, models/, benchmarks/, runs/ feature components
src/lib/api/      typed Tauri command client (call, ApiError) and one function per command; types mirror the Rust types
src/lib/queries/  TanStack Query hooks (polling, mutations, cache invalidation)
src/lib/          format.ts (Intl formatting) and errors.ts (error code → message + next step)
```

Tests are `*.test.ts(x)` files next to the code they cover, run with Vitest + Testing Library (jsdom).
